## 🚀 Proyectos Destacados

### 🔄 Arquitectura ETL y Dashboards Automatizados — People Analytics
> Pipeline de datos de extremo a extremo para gestión humana con visualización automatizada

**¿Qué resuelve?** Centraliza y procesa datos de múltiples fuentes de RRHH (nómina, asistencia, desempeño) eliminando procesos manuales y generando inteligencia en tiempo casi real.

| Tech Stack | Tools |
|---|---|
| Python · Pandas · Apache Spark · Apache Airflow · AWS S3 · Redshift · Power BI | Git · GitHub · Docker |

**Logros clave:**
- ⚡ Reducción del 80% en tiempo de consolidación de datos mediante pipelines ETL automatizados
- 📊 Dashboards de KPIs (rotación, ausentismo, headcount) con actualización automática para dirección
- 🤖 Segmentación de empleados con K-Means para identificar perfiles de riesgo de retiro
